OnePDF is a secure, 100% offline desktop application designed to handle sensitive documents without relying on external cloud services. **Your files never leave your machine.**

## 🚀 The Problem We Solve
Current PDF tools often force users to upload highly sensitive documents (medical records, legal contracts, IDs) to remote servers for simple tasks like merging, compressing, or splitting. OnePDF mitigates this critical security vulnerability by providing robust PDF manipulation entirely offline.

## 🧰 Features (Current & Planned)
- [x] **100% Offline:** Total privacy for your sensitive documents.
- [ ] **PDF Merge:** Combine multiple PDFs into a single document.
- [ ] **PDF Split & Extract:** Separate pages with ease.
- [ ] **PDF Compress:** Reduce file sizes without losing quality locally.
- [ ] **Rotate & Rearrange:** Manage page order seamlessly.

## 🛠️ Tech Stack
