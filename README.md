# OnePDF

OnePDF is a secure, offline desktop application designed to handle sensitive documents without relying on cloud services. Your files never leave your machine.

## 🚀 Features
*   **100% Offline:** Total privacy for your sensitive documents.
*   **PDF Merge:** Combine multiple PDFs into a single document (In Development).

## 🛠️ Tech Stack
*   **Framework:** Electron + Vite
*   **Frontend:** React.js
*   **PDF Processing:** pdf-lib

## 💻 Setup
1. Clone the repo: `git clone https://github.com/yourusername/OnePDF.git`
2. Install dependencies: `npm install`
3. Run locally: `npm run dev`
